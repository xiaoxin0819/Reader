## Reader v1.0.3

下载下面的 **Reader.zip**，解压后双击 `Reader.exe` 即可（无需安装 Node.js）。

### 本次更新

**发现页大幅提速**

- 新增书列表缓存：同一分类再次打开从 1.3~2.9 秒降到约 **110ms**
- 缓存过期不再让你等：先显示上次结果，同时在后台悄悄刷新
- 打开发现页时后台自动预热「排行榜 + 热门标签」两组（共 34 项），
  预热耗时从 118 秒优化到 **8 秒**，且全程不影响你点击（实测点击 17~19ms）
- 清缓存后会依次自动重建：最近阅读 → 书架 → 发现页

**书源防封禁更省心**

- 书源管理里新增「限制该书源（防封禁）」开关，一个勾选同时管住三件事：
  禁止导出 TXT、禁止后台预热、并发上限 3
- 速读谷等易触发风控的书源已自动启用
- 修复 exe 版登录态可能写错目录导致要反复登录的问题
- 设备标识改为本机唯一且持久（原来所有用户共用一个固定值，容易被风控）

**界面**

- 顶栏新增「自动下一章」按钮，一键开关
- 顶栏「上一章 / 下一章」现在真的翻章了（原来翻的是整本），
  鼠标悬停能看到快捷键：`←` `→` `PageUp` `PageDown`
- 字体选择器重做：每个选项用对应字体显示，自定义字体可直接删除，
  导入再多字体也不会撑长菜单（固定高度 + 滚动）
- 阅读设置面板整体放大，更易操作
- 修复替换净化面板里书源组按钮点了没反应的问题

**稳定性**

- 支持同时开多个 Reader 实例（不同数据目录互不干扰）
- 修复内置浏览器偶发「打开失败」的问题

### 下载

`Reader.zip`（35 MB）

### 首次使用

1. 解压到任意文件夹（**不要**放 `C:\Program Files` 等需要管理员权限的目录）
2. 双击 `Reader.exe`，浏览器会自动打开
3. 数据全部存在 exe 同级目录，整个文件夹拷走即带走全部数据

### 数据目录说明

```
reader.config.json   配置（书架、阅读设置、书源开关）
sources/             书源
cache/               正文 / 目录 / 登录态缓存
fonts/               自定义字体
```

详见 [README](https://github.com/xiaoxin0819/Reader#readme)。
